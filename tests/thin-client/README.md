# Тесты адаптивного Тонкого веб-режима (`web/`)

Покрытие (Этап 4):
- Адаптивный режим того же веб-приложения без отдельной сборки и без локальной БД/кэша документов
- Отображение только 5 очередей («Мои задачи», «На подпись», «Ознакомление», «Новые», «Срочные»)
- Потоковый просмотр вложения с сервера и действия в 1 клик
