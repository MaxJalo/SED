# Тесты внешнего шлюза к Оркестратору (`M09`)

Покрытие (Этапы 1–3):
- Проверка токена сессии в `AUTH_BASE_URL/api/v1/auth/me` и чтение оргструктуры `/api/v1/auth/directory`
- Создание и синхронизация поручений `POST /api/v1/platform-tasks` (закрытие только автором)
- Отправка уведомлений `POST /api/v1/notifications` с обязательным `source_document_id`
- Однократное создание внешнего заказа при подписании договора с `customer_contract = true`
