# Тесты шлюза Outbox к внешнему учёту 1С

Покрытие (Этап 2):
- Атомарная постановка события в `outbox_events` в одной транзакции с выдачей регистрационного номера
- Автономная работа СЭД при недоступности 1С (`AC-09`): чтение, черновики, маршруты и регистрация без ошибок
- Экспоненциальные повторы и идемпотентная доставка без дублей после восстановления связи с 1С
