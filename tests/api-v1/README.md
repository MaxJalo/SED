# Тесты внешнего контракта REST API `/v1`

Покрытие (Этапы 1–3):
- Идемпотентность `POST /v1/documents` и `POST /v1/documents/{id}/register` (`Idempotency-Key`)
- Курсорная пагинация (`limit <= 100`, непрозрачный `cursor`) и серверная фильтрация прав / локальных тегов
- Потоковая загрузка и скачивание файлов до 50 МБ (`sha256`, дедупликация, выпуск версии `N+1` после старта маршрута)
- Машина состояний (9 статусов), пауза маршрута (`Приостановлено`), 7 примитивов шагов, флаги шаблонов
- Поэтапная регистрация, выгрузка листа согласования `.docx`, заявки на доступ, календарь и отчёты SLA
