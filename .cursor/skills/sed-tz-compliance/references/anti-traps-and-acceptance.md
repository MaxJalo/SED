# Типовые ошибки (анти-ловушки) и приёмочные сценарии `AC-01`–`AC-12`

## 1. Реестр анти-ловушек при реализации

| № | Ловушка (чего делать НЕЛЬЗЯ) | Правильное поведение по ТЗ 3.1 |
| --- | --- | --- |
| 1 | Смешивать `temp-auth` с ядром СЭД (общие пакеты, единый `docker-compose.yml`). | `temp-auth` — отдельный Go-модуль и контейнер в `docker-compose.dev-auth.yml`. |
| 2 | Переносить в СЭД заявки на расходование ДС, поручения экспедитору, приказы о депремировании. | Эти финансово-кадровые формы остаются во внешнем учёте 1С. |
| 3 | Путать `platform_tasks` с учётным документом поручений 1С. | Поручения сервиса создаются и синхронизируются только в `platform_tasks` Оркестратора. |
| 4 | Хранить локально логины, пароли, email или таблицу уведомлений. | Только `orchestrator_user_id`; уведомления уходят в `POST /api/v1/notifications` с `source_document_id`. |
| 5 | Автоматически переводить статус карточки при просрочке SLA. | Просрочка подсвечивает «Срочные» и шлёт уведомление, но статус не меняет. |
| 6 | Перезаписывать файл текущей версии после старта маршрута. | Любое добавление/удаление/замена файла после старта выпускает версию `N+1`. |
| 7 | Сбрасывать `plan_due_at` при делегировании или переписывать уже выданные задачи при смене руководителя/замещения. | Замещение действует только на новые шаги; уже выданные задачи не переписываются; делегирование не сбрасывает срок. |
| 8 | Использовать `OFFSET`-пагинацию или фильтровать права после `LIMIT`. | Строго курсорная пагинация (`limit <= 100`, `cursor`), фильтрация прав и локальных тегов на сервере до нарезки. |
| 9 | Блокировать работу СЭД при падении 1С. | При недоступности 1С работают журналы, карточки, файлы, маршруты и регистрация; выгрузка ждёт в `outbox_events`. |
| 10 | Писать `if docType == "Договор"` в коде движка. | Логика маршрута управляется декларативным шаблоном, 7 примитивами и флагами. |

## 2. Матрица приёмо-сдаточных сценариев (`AC-01`–`AC-12`)

- **AC-01 (Единство клиентов и SSO):** 3 клиента открывают одну карточку без повторного пароля; отзыв/блокировка пользователя мгновенно закрывает доступ (`401`).
- **AC-02 (Идемпотентность и версионность):** повтор с тем же `Idempotency-Key` возвращает ту же карточку и номер; замена файла после старта маршрута создаёт версию `2`, оставляя версию `1`.
- **AC-03 (Входящий с рассмотрением):** после регистрации и резолюции параллельный `review` (1 раб. дн.) с рекомендацией создаёт бессрочное `acknowledgment` (не влияет на 15-дневный цикл) и `platform_tasks`; возврат/отказ на `review` возвращает на `resolution` без остановки.
- **AC-04 (Возврат vs Отзыв):** возврат согласующего -> `Возвращён на доработку`; отзыв автора (до поручений / до резолюции) -> `Отозван автором`; оба перезапускаются с шага 1 с сохранением истории.
- **AC-05 (Отказ и связь «на основании»):** отказ -> `Отклонён` без номера и заказа; создание «на основании» формирует новый черновик со связью без изменения вида исходного документа.
- **AC-06 (Договор с заказчиком):** при `customer_contract = true` после подписания однократно создаётся `external_orders`; повторное подписание или `допсоглашение` второй заказ не создают.
- **AC-07 (SLA, важность, «Срочные»):** `Повышенная` = `ceil(days/2) >= 1`, `Немедленная` = `4 ч`; «Срочные» <= 2 раб. дн.; просрочка шлёт уведомление с `source_document_id`, статус не меняет.
- **AC-08 (Серверные замещения):** новая задача сразу идёт заместителю «за кого»; выданные задачи не переписываются при смене руководителя.
- **AC-09 (Автономность при отказе 1С):** при отключённой 1С журналы, файлы и регистрация работают; после восстановления воркер доставляет `outbox_events` с тем же номером без дублей.
- **AC-10 (Права, изоляция, аудит):** чужое юрлицо и наблюдатель без права не открывают карточку; пароли 1С никуда не передаются; заявки, смены прав и изменения реквизитов пишутся в append-only аудит с прежним и новым значением. Просмотр карточки и скачивание файла журнал не пополняют.
- **AC-11 (Журналы и поэтапность):** номер уникален в `(organization_code, journal_id, год)`; дозаполнение пустых второстепенных полей после регистрации не меняет номер.
- **AC-12 (Флаги, пауза, рецензия, Word):** по умолчанию `stop_on_reject = true` останавливает группу; при паузе маршрута статус карточки не меняется; возврат/отзыв родителя ставит подчинённых на паузу; боковая рецензия без SLA; картинка факсимиле в `.docx` не заменяет фиксацию подписи в БД.
